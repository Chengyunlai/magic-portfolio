## 项目简介

Ops Agent 是一个运行在本地终端的 Kubernetes 运维台：可视化浏览集群资源，用自然语言下达扩缩容、排错和查日志等指令。

## 项目特点

- 使用 Textual 构建终端用户界面。
- 通过 Function Calling 连接 Kubernetes API，不依赖 kubectl。
- 将 AI 诊断融入日常运维流程。
