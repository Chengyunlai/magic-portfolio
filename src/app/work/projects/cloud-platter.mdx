## 项目简介

Cloud Platter 是一个面向 macOS 的桌面体验实验：播放网易云音乐时，让一台会随旋律转动的黑胶唱机留在桌面上。

## 项目方向

- 将音乐播放状态转化为持续、克制的桌面动效。
- 探索原生 macOS 体验与轻量级桌面工具的结合。
- 用 Swift 构建一个小而完整的开源应用。
