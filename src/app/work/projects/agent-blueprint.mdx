## 项目简介

Agent Blueprint 用来整理 Agent 开发从学习、设计到落地的完整路径，让相关规范、架构实践与代码仓库能够长期演进。

## 项目方向

- 记录 Agent 工程的学习路径和实践原则。
- 沉淀可复用的项目结构与工程约束。
- 让多个 Agent 项目共享清晰、稳定的基础设施。
